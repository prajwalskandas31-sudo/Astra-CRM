## 2. Data Record Upload Option (Super Admin Only)

### 2.1 Purpose & Central Reference Database
- Allows the Super Admin to upload master datasets/records that serve as the central reference database for lead comparison and duplicate prevention across the CRM system.

### 2.2 File Format & Strict Validation Rules
- **Supported Format**: Excel (`.xlsx`, `.xls`) & CSV sheet upload.
- **Mandatory Columns**: `CONTACT NAME`, `CONTACT NUMBER`, `LANGUAGE`.
- **Strict Order Requirement**: Column order must strictly follow:
  1. `CONTACT NAME`
  2. `CONTACT NUMBER`
  3. `LANGUAGE`
- **Error Handling**: If columns are missing or out of sequence, the system halts processing immediately and throws the exact error message:
  > `"Invalid File Format"`

---

## 3. Sub-Block 1: Bulk Upload Option (Super Admin Only)

### 3.1 Data Input & Column Sequence Check
- **Strict Order Requirement**: Excel/CSV headers must strictly follow `1) CONTACT NAME, 2) CONTACT NUMBER, 3) LANGUAGE`.
- **Error Halting**: If headers fail order or presence validation, throw exact error: `"Invalid File Format"`.

### 3.2 Lead Validation Categorization
- **Data Record Comparison**: Uploaded leads are compared directly against the existing master data records uploaded by the Super Admin.
- **Successful Leads**: New leads that do not exist in the master data record. Automatically added to system database with default disposition `"New Lead"`.
- **Duplicate Leads**: Leads whose contact number already exists in the master data record. Detected, merged/deleted from the upload file, and blocked from re-creation.
- **Failed Leads**: Uploaded records missing required individual row data (e.g. missing name, contact number, or language).

### 3.3 Analytics, Visualization & Data Export
- **Visual Analytics**: Interactive Bar & Pie charts displaying counts of Successful, Duplicate (Merged/Deleted), and Failed leads.
- **Data Export Buttons**: Single-click buttons to download 3 separate Excel/CSV files:
  - `Successful_Leads.csv`
  - `Duplicate_Leads.csv`
  - `Failed_Leads.csv`

### 3.4 Language-Based Filtering & Dynamic Lead Assignment (Block 1 Integration)
- Successful leads are filtered by the `LANGUAGE` field specified in the Excel sheet.
- **Assignment Engine**: Super Admin can select a target language and assign confirmed leads to system users (Executives/Team Leads created in Block 1) in custom quantities.

---

## 4. Sub-Block 2: Single Upload Option (All Users Access)

### 4.1 Data Input Fields
- Contact Name
- Contact Number
- Language

### 4.2 Database Comparison & Warning
- Uploaded entry is compared against the central master data records uploaded by the Super Admin.
- **If New Lead**: Automatically saved into the main database with default disposition `"New Lead"`.
- **If Duplicate Lead**: Creation is blocked and displays exact warning:
  > `"Lead already exists, please contact Super Admin."`

---

## 5. Sub-Block 3: Reports (Export & Download Feature)

### 5.1 Download Mechanism
- **Download Report Button**: Instant PDF export and download feature built into the UI.

### 5.2 PDF Report Content Structure
- **Super Admin View (Page / Section 1)**:
  - Total count of unassigned leads available in the system.
  - Data strictly categorized and broken down language-wise based on the `LANGUAGE` column.
- **User Level View - Integration with Block 2 (Page / Section 2)**:
  - Total count of new leads assigned and currently present under each user's disposition.
  - **Calculation Logic**: Aggregating and counting all entries with `"New Lead"` status within the Block 2 CURRENT DISPOSITION section for every respective user.
