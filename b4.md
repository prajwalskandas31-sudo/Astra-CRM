# BLOCK FOUR - Requirements Analysis & Specification Log

## Overview
This document serves as the tracking log and formal specification breakdown for **BLOCK FOUR: Lead Summary – Super Admin Only (Inside Super Admin Panel)** of the CRM system, derived from `Block 4.pdf` and cross-block system integrations.

---

## 1. General Scope & Access Control

### 1.1 Scope & Authority
- **Super Admin Exclusive**: Access to Block 4 features is strictly reserved for the **Super Admin** inside the Super Admin panel.
- **Role Isolation**: Non-Super Admin roles (Admin, Manager, Team Leader, Executive) do not have access to this view.

### 1.2 Core Capabilities
- Management, tracking, multi-dimensional filtering, deletion, and reassignment of assigned leads and assignment files post-assignment.

---

## 2. Lead Request Management

### 2.1 Inbound Lead Requests Queue
- Displays all lead requests submitted by users/teams under Super Admin / Admin.
- Displays requesting user, team, requested language, quantity, request date, and status.

### 2.2 Auto-Disappear Rule
- Once leads are assigned by the Super Admin to fulfill an inbound request, the request is automatically marked complete and **disappears** from the active inbound requests dashboard.

### 2.3 Language Distribution
- Super Admin receives all master/unassigned leads and distributes them to users based on language matching.

---

## 3. Lead Assignment History & Advanced Filtering

### 3.1 Visibility
- Complete history of lead assignment instances (batches/files) assigned to users by Super Admin or Admin.

### 3.2 Advanced Multi-Criteria Filtering
Super Admin can filter lead history individually or in combination using:
1. **User Dropdown**: Filter by specific assigned user.
2. **Date Lookup / Date Picker**: Filter leads assigned on a specific instance/date.
3. **Language Dropdown**: Filter by target language.
4. **Teamwise Dropdown**: Filter by target team.
5. **User Disposition Dropdown**: Filter by disposition status updated by the user (New Lead, Interested, Call Back Later, Not Interested, Paid, etc.).

### 3.3 View Density & Pagination Control
- Adjustable pagination density options: `10`, `20`, `50`, `100`, `500`, `1000` leads per page.

---

## 4. Real-Time Disposition & Status Tracking

### 4.1 Instance Tracking Modal / Detail View
Upon clicking/opening an assignment history instance, Super Admin can view:
- **Total Leads Uploaded / Assigned**: Total count of leads in that specific instance batch.
- **Count of Dialed Leads**: Count of leads where a disposition or call attempt was logged.
- **Count of Uncontacted Leads Left**: Count of leads still in default `New Lead` uncontacted state.
- **Disposition Status Breakdown**: Detailed real-time count for all user-updated disposition statuses.

---

## 5. File & Granular Lead Operations (Deletion & Reassignment)

### 5.1 File Level Operations
- **Single & Bulk Deletion**: Select one or multiple assignment files to delete.
- **File Reassignment**: Reassign an entire file/batch of leads to another user at Super Admin discretion.

### 5.2 Granular Lead Operations
- **Granular Lead Selection**: Checkbox selection for individual leads or groups of leads.
- **Granular Reassignment**: Reassign selected lead(s) to another user.
- **Granular Deletion**: Delete selected lead(s) from the system.
