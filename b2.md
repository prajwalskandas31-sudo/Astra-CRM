# BLOCK TWO - Requirements Analysis & Specification Log

## Overview
This document serves as the tracking log and formal specification breakdown for **BLOCK TWO** of the CRM system, derived from `Block_2.pdf` and accompanying reference UI designs (`connect.neodove.com/settings/pipeline`).

---

## 1. Dispositions & Pipeline Management (Settings)

### 1.1 Location & Creation Rights
- **Settings Menu Placement**: A dedicated **Dispositions & Pipeline Manager** section under System Settings.
- **Super Admin Authority**:
  - Only the **Super Admin** can create, edit, re-order, or delete lead dispositions/stages.
  - Examples of Dispositions/Stages:
    - *Interested*
    - *Not Interested*
    - *Call Back Later*
    - *Give Demo Call*
    - *New*
    - *Follow Up*
    - *Trial Calls*
    - *Commitment*
    - *Paid / Converted*

### 1.2 Dashboard Integration & Shortcut Buttons
- **Dynamic Shortcut Generator**: Every disposition created by the Super Admin automatically generates corresponding dynamic shortcut action buttons and filter pills on the CRM Dashboard.
- **Visual Pipeline Board**: Drag-and-drop / stage indicator showing leads grouped by disposition stage.

---

## 2. Post-Call Workflow & Multi-Role Access

### 2.1 Post-Call Disconnect Workflow
- Immediately after a call disconnects (or when logging a call interaction), a **Post-Call Outcome Popup** appears.
- Prompts the user to select one of the configured disposition shortcut buttons and optionally add call notes or set a follow-up callback timer.

### 2.2 Access Across All User Roles
- Any user who holds assigned leads—including **Super Admin**, **Admin**, **Manager**, **Team Leader**, and **Executive**—can access the disposition shortcut buttons to update their assigned leads' status in real-time.

---

## 3. Implementation Roadmap
- **State Extension (`CRMContext`)**:
  - Add `dispositions` array state (default: *New*, *Call Back Later*, *Give Demo Call*, *Interested*, *Follow Up*, *Not Interested*, *Commitment*, *Paid*).
  - Methods: `addDisposition()`, `editDisposition()`, `deleteDisposition()`, `updateLeadDisposition()`.
- **CRM Dashboard Component (`src/components/CRMDashboard.jsx`)**:
  - Main user dashboard featuring dynamic disposition shortcut buttons, post-call workflow simulator, and lead pipeline board.
- **Settings Pipeline Component (`src/components/DispositionsManager.jsx`)**:
  - Super Admin creation interface matching NeoDove pipeline settings screenshot.
